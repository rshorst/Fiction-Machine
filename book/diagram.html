Isolation is the method

Frances builds each character in a separate run with no memory, so the relations are found afterwards, not planned. The four annotators never see each other's notes, so Sean has real disagreements to weigh.

Distance is deliberate

Richard and Material run without memory: Richard revises at a distance from his own draft, and Material checks each claim cold. Guha reads draft 02 with no annotations or letters at all.

Every stage can resume

Each step checks whether its file already exists and skips it if so. A failed run picks up where it stopped, or rolls back to the checkpoint after Frances.
